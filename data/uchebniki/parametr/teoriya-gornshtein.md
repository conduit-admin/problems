# Параметр: теория по Горнштейну

## Зачем это нужно

Конспект книги Горнштейна, Полонского и Якира — по тем темам, которых нет
у Пратусевича (`teoriya-pratusevich.md`). Заполняется по главам; сейчас
есть пункты В и Г §1 главы II «Свойства решений» и «Параметр как
равноправная переменная», стр. 37–57, §2 главы II «Свойства функций»,
стр. 58–89, глава III «Квадратичная функция», стр. 152–203, и §2 главы IV
«Методы поиска необходимых условий», стр. 234–267.

Ссылки — номер задачи книги (II.N, III.N, IV.N) и страница: в файле
`tex/reference/gornshtein/zadachi-s-parametrami.pdf` нумерация совпадает
с напечатанной. Ответы всех приведённых задач пересчитаны; где книга
ошибается, это сказано на месте и собрано в конце. Упражнения без решений
(ответы — с 268-й страницы) сюда не переписаны: это задачник, а не теория.

Обозначения: трёхчлен $f(x) = Ax^2 + Bx + C$ — заглавными, чтобы
не путать коэффициенты с параметром; $D$ — дискриминант;
$x_0 = -\frac{B}{2A}$ — абсцисса вершины.

## Глава II, §1. Свойства решений; параметр как переменная

*Стр. 37–57, пункты В и Г, задачи II.56–II.94.* Пункты А «Ветвление»
и Б «Количество решений» есть у Пратусевича и сюда не взяты.

### В. Свойства решений

*Стр. 37–49, задачи II.56–II.68.*

Название пункта книга сама называет условным. Общее у задач — требование
не к числу решений, а к самому множеству решений: оно должно лежать
в заданном множестве или содержать заданное. Сюда же книга относит
равносильность и следствие: «второе — следствие первого» значит, что
множество решений первого вложено в множество решений второго.

**Решения из заданного множества.**

- II.56: рациональные решения $x + \sqrt2 = x\sqrt2 + a^2$ при рациональном $a$.
  Запись $x - a^2 = \sqrt2(x - 1)$: слева рациональное число, справа
  рациональное только при $x = 1$. Ответ: при $a = \pm1$ $x = 1$; при
  остальных рациональных $a$ рациональных корней нет.
- II.57: все решения $\frac{a - 1}{x + 6} = \frac{2x + 7}{(x + 2)^2 - x - 22}$
  неположительны. Знаменатель справа — $(x + 6)(x - 3)$, уравнение сводится
  к $x(a - 3) = 3a + 4$, $x \ne -6$, $x \ne 3$. Корень $\frac{3a + 4}{a - 3}$
  не равен 3 ни при каком $a$, а $-6$ — при $a = \frac{14}9$. Ответ:
  $-\frac43 \le a < \frac{14}9$ или $\frac{14}9 < a < 3$.
- II.58: только положительные решения у
  $\left|\frac{(a - 1)x - (2a - 1)}{x - 1}\right| + \left|x - |1 - a| + \frac12\right| = 0$.
  Сумма модулей — ноль, только когда оба слагаемых ноль:
  $x = \frac{2a - 1}{a - 1} = |1 - a| - \frac12$, $x > 0$, $x \ne 1$.
  Ответ: $a = -1$ или $a = \frac{9 + \sqrt{41}}4$.
- II.59: не меньше четырёх целых решений у
  $a^2\left|a + \frac x{a^2}\right| + |1 + x| = 1 - a^3$. При $a \ne 0$ это
  $|x + a^3| + |x + 1| = 1 - a^3$: сумма расстояний до точек $-a^3$ и $-1$
  равна расстоянию между ними, и решения заполняют отрезок $[-1; -a^3]$.
  Четыре целых в нём — $-1$, $0$, $1$, $2$, то есть $-a^3 \ge 2$. Ответ:
  $a \le -\sqrt[3]2$.

Книга понимает «все решения неположительны» как «решения есть, и все
неположительны»: в II.57 значения $a = 3$ и $a = \frac{14}9$, при которых
решений нет, в ответ не взяты. Это то же прочтение, что в III.89 и III.92,
и обратное к III.6 и III.90.

**Множество решений содержит заданное.**

- II.60: $(x - 3a)(x - a - 3) < 0$ при всех $x \in [1; 3]$ — отрезок лежит
  в интервале между $3a$ и $a + 3$. Ответ: $0 < a < \frac13$.
- II.61: всякое решение $(0{,}5)^{\frac1{2(x - 1)^2}} \le (0{,}25)^{\frac1{(3 - x)^2}}$
  входит в область определения $\lg(9 - 16a^4x^2)$. Решения неравенства —
  $[-1; 1) \cup \left(1; \frac53\right]$, область определения при $a \ne 0$ —
  $|x| < \frac3{4a^2}$, при $a = 0$ — вся прямая. Ответ:
  $-\frac{3\sqrt5}{10} < a < \frac{3\sqrt5}{10}$.
- II.62 — та же задача, что IV.126 ($x + \sqrt{x^2 - 2ax} > 1$ на
  $\left[\frac14; 1\right]$), решённая напрямую: при $x \le 1$ неравенство
  равносильно $x(1 - a) > \frac12$. Ответ: $a < -1$.
- II.63: не больше четырёх целых решений у
  $x(x - 4) + a^2(a + 4) \le ax(a + 1)$, то есть $(x - a^2)(x - a - 4) \le 0$.
  Решения — отрезок между $a^2$ и $a + 4$; книга перебирает, между какими
  целыми лежит его левый конец. Ответ: $-\sqrt6 < a < \sqrt{12}$, $a \ne 0$,
  $a \ne 1$ — при $a = 0$ и $a = 1$ в отрезке $[a^2; a + 4]$ пять целых.

**Равносильность и следствие.**

- II.64 — IV.125, решённая без выгодной точки. Решения
  $\sqrt{x^2 + 4x + 3} \ge -1 - x$ — луч $x \ge -1$; на нём уравнение
  $|x - a| - |x + 1| = 2$ становится $|x - a| = x + 3$ и должно выполняться
  на всём луче. Бесконечно много корней это уравнение имеет только при
  $a = -3$. Ответ: $a = -3$.
- II.65: равносильность $\sin2x(\sin2x - 1) = 0$ и
  $(a + 3)\sin^22x - \sin2x\cos4x - (a + 4)\sin2x = 0$. Второе раскладывается:
  $\sin2x(\sin2x - 1)\left(\sin2x + \frac{a + 5}2\right) = 0$. «Лишнее»
  уравнение $\sin2x = -\frac{a + 5}2$ не должно давать новых корней: его правая
  часть равна 0 или 1 либо больше 1 по модулю. Ответ: $a \le -7$, $a = -5$
  или $a > -3$.
- II.66: при каких $a$ из того, что $x$ — корень
  $x^2 + \left(3 - \frac a4\right)x = (a - 1)\left(\frac{3a}4 + 2\right)$,
  следует $|x - 1| + |x + a| > |1 + a|$. Корни $a - 1$ и $-\frac{3a + 8}4$,
  неравенство значит «точка вне отрезка с концами 1 и $-a$» — тот же смысл
  модуля, что в II.59. Остаётся подставить оба корня. Ответ: $-4 < a < \frac12$
  или $2 < a < 8$.
- II.67: произведение корней $(x + 2a)(x^2 - a^2 - 2a - 1) = 0$ меньше
  наименьшего корня. Корни $-2a$, $a + 1$, $-(a + 1)$; наименьший из них —
  $-2a$ при $a > 1$, $a + 1$ при $a < -1$, $-(a + 1)$ при $-1 < a < 1$.
  Ответ: $a < -\frac{1 + \sqrt3}2$ или $a = 1$. **В книге потеряно $a = 1$:**
  там корни $-2$ и $2$, произведение $-4$ меньше $-2$. Книга перемножает три
  корня, считая $-2$ дважды, хотя в III.78 кратный корень считает за один.
- II.68: положительных корней больше, чем отрицательных, у
  $(x - p)^2\bigl(p(x - p)^2 - p - 1\bigr) = -1$. Относительно $t = (x - p)^2$
  уравнение раскладывается: $(t - 1)(pt - 1) = 0$. Корни $p \pm 1$ и при $p > 0$
  ещё $p \pm \frac1{\sqrt p}$. Ответ: $p \ge 1$ (при $p = 1$ корни $0$ и $2$).

### Г. Параметр как равноправная переменная

*Стр. 50–56, задачи II.88–II.94.*

Формально параметр — такая же переменная, как $x$, и $f(x; a)$ — функция
двух переменных. Пункт показывает аналитическую сторону этого взгляда;
графическая — плоскость $(x; a)$, II §4, она есть у Пратусевича. У него же
приём «решить относительно другой буквы» занимает одну строку (§78,
«смена ролей»); здесь он развёрнут на задачах.

**Система в переменных $(x; a)$.** II.88: общий действительный корень
у $x^2 + x + 4a = 0$ и $a^2x^2 + ax + 4a = 0$. Ответ — вторые координаты
решений системы из обоих уравнений. Разность уравнений:
$(1 - a)x\bigl((1 + a)x + 1\bigr) = 0$, три случая. При $a = 1$ уравнения
совпадают и действительных корней не имеют; $x = 0$ даёт $a = 0$, и тогда
второе уравнение — тождество; $x = -\frac1{1 + a}$ приводит к
$a(4a^2 + 8a + 3) = 0$. Ответ: $a = 0$, $a = -\frac12$, $a = -\frac32$.

**Решить относительно параметров.** II.89 — два параметра. Система
$2a + \frac{2b^2}a = x\left(1 + \frac ba\right) + y\left(1 - \frac ba\right)$,
$\frac{2a}b - 2ab = x\left(\frac1b - a\right) + y\left(\frac1b + a\right)$
линейна по $x$ и $y$, но проще решить её относительно $a$ и $b$. После
умножения на $a^2$ и на $b$ сумма уравнений даёт
$2a(a^2 + 1) = (x + y)(a^2 + 1)$, то есть $a = \frac{x + y}2$, а затем
$b = \frac{x - y}2$. Ответ: при $a \ne 0$, $b \ne 0$ $x = a + b$, $y = a - b$;
при $a = 0$ или $b = 0$ решений нет.

**Квадратное относительно параметра.** Если уравнение квадратное по $a$
и его дискриминант по $a$ — полный квадрат, левая часть раскладывается
на множители, которые по $x$ уже просты.

- II.90 — та же задача, что II.179: $\sqrt{a + \sqrt{a + \sin x}} = \sin x$
  имеет решения. При $t = \sin x$: $a + t = (t^2 - a)^2$, $0 \le t \le 1$,
  $t^2 \ge a$. По $a$: $a^2 - a(2t^2 + 1) + t^4 - t = 0$, корни
  $a = t^2 + t + 1$ (противоречит $t^2 \ge a$) и $a = t^2 - t$. Ответ:
  $-\frac14 \le a \le 0$.
- II.91: для каждого $a \ge 0$ решить $a^3x^4 + 6a^2x^2 - x + 9a + 3 \ge 0$.
  Прямо не раскладывается ни по $x$, ни по $a$. Идея — умножить на $a$
  и положить $t = ax$: $t^4 + 6at^2 - t + 9a^2 + 3a = 0$ квадратное по $a$
  с дискриминантом $9(2t + 1)^2$. Отсюда при $a > 0$ неравенство —
  $(a^2x^2 + ax + 3a + 1)(ax^2 - x + 3) \ge 0$, и первый множитель
  положителен. Ответ: при $a = 0$ $x \le 3$; при $0 < a < \frac1{12}$
  $x \le \frac{1 - \sqrt{1 - 12a}}{2a}$ или $x \ge \frac{1 + \sqrt{1 - 12a}}{2a}$;
  при $a \ge \frac1{12}$ $x$ любое.
- II.94 — уравнение без параметра: $\sqrt{5 - x} = x^2 - 5$. Если число 5
  заменить буквой $a$, равенство $a - x = (x^2 - a)^2$ квадратное по $a$:
  $a = x^2 + x$ или $a = x^2 - x + 1$. Ответ: $x = \frac{-1 - \sqrt{21}}2$
  или $x = \frac{1 + \sqrt{17}}2$. Книга этим и объясняет, зачем такая
  задача в задачнике о параметрах: идею легче увидеть, если уравнение
  «параметризовать».

**Семейство кривых.** Точка $(x_0; y_0)$ лежит хотя бы на одной кривой
семейства $F(x; y; p) = 0$ $\iff$ уравнение $F(x_0; y_0; p) = 0$
относительно $p$ имеет решение. Множество, которое заметают кривые, —
это множество точек, для которых найдётся $p$. Других задач с этим
квантором в пункте нет.

- II.92: точки, через которые не проходит ни одна кривая
  $y = x^2 - 2(1 + 2p)x + 2p^2 - 1$. Квадратное по $p$:
  $2p^2 - 4xp + x^2 - 2x - 1 - y = 0$, его дискриминант
  $8\bigl((x + 1)^2 + y\bigr)$ должен быть отрицательным. Ответ:
  $y < -(x + 1)^2$ — точки под параболой $y = -(x + 1)^2$. **В книге ответ
  неверный:** $y < -x^2 - 3$ — в решении уравнение по $p$ выписано
  с $x^2 - y - 3$ вместо $x^2 - 2x - 1 - y$. Проверка: через $(0; -2)$
  не проходит ни одна кривая ($2p^2 - 1 = -2$ невозможно), а по ответу книги
  проходит.
- II.93 — два параметра. Один из корней $x^{12} - abx + a^2 = 0$ больше 2;
  при каких $a$ отсюда следует $|b| > 64$? Для корня $x_0 > 2$ равенство
  $a^2 - bx_0a + x_0^{12} = 0$ — квадратное по $a$, и оно выполнено, значит,
  дискриминант $b^2x_0^2 - 4x_0^{12} \ge 0$: $|b| \ge 2x_0^5 > 64$. Ответ:
  при любом $a$.

## Глава II, §2. Свойства функций

*Стр. 58–89, задачи II.107–II.180.*

Уравнение $f(x) = g(x)$ — вопрос о том, где совпадают значения двух
функций, и ключ к решению часто даёт не преобразование, а свойства этих
функций. Пункты идут по схеме исследования функции: область значений,
наибольшее и наименьшее значения, монотонность, чётность и периодичность.
Область определения отдельным пунктом не выделена — она учитывается всегда.

### А. Область значений

*Стр. 58–67, задачи II.107–II.115.*

**Прямые задачи на область значений.**

- II.107: множество значений $\left(\frac13\right)^{x^2 + 2x + a^2 - 3a}$
  не пересекается с $[3; +\infty)$. Выделение полного квадрата даёт
  значения $\left(0; \left(\frac13\right)^{a^2 - 3a - 1}\right]$. Ответ книги:
  $a < 0$ или $a > 3$. В условии спрашивают целые $a$; для них ответ —
  $a \le -1$ или $a \ge 4$.
- **Значение функции как параметр.** Чтобы найти область значений
  $y = f(x)$, решают уравнение $f(x) = y$ относительно $x$ и выясняют,
  при каких $y$ оно разрешимо. II.108: при $a > 0$ значения
  $\frac{a^{x-1} + 5}{a^x + 3a}$ — интервал между $\frac1a$ и $\frac5{3a}$
  (при $a = 1$ — одна точка $\frac32$). Интервал без чётных чисел лежит
  в $[0; 2]$ или в $[2; 4]$. Ответ: $a \ge \frac56$ или $\frac5{12} \le a \le \frac12$.
- II.109: $[1; 2]$ лежит в области значений $\frac{x + 1}{4x^2 - a}$ $\iff$
  при каждом $b \in [1; 2]$ уравнение $b(4x^2 - a) = x + 1$ разрешимо:
  $1 + 16ab^2 + 16b \ge 0$ при всех $b$, то есть $-16a$ не больше наименьшего
  значения $c^2 + 16c$ на $\left[\frac12; 1\right]$, $c = \frac1b$. Ответ:
  $a \ge -\frac{33}{64}$. По сути — задача с кванторами: «при всех $b$
  найдётся $x$».

**Область значений нужна по ходу решения.**

- II.110: $4 + 25^b$, $a$, $5^{-b}$ — геометрическая прогрессия при каком-то $b$.
  $a^2 = 5^b + 4 \cdot 5^{-b}$, значения правой части — $[4; +\infty)$.
  Ответ: $|a| \ge 2$.
- II.111: система с $\operatorname{arctg}x$ и $e^z$ после замены становится
  линейной, а ограничения дают области значений $\operatorname{arctg}$ и $e^z$.
  Ответ: при $\frac12 < a < \frac\pi2$ $x = \operatorname{tg}a$, $y = 2$,
  $z = \ln(2a - 1)$; иначе решений нет.

**Тригонометрическая подстановка.** Если переменная пробегает ровно
множество значений какой-то функции, её можно этой функцией заменить:
$|x| \le 1$ — $x = \sin\alpha$ или $x = \cos\alpha$; любое $x$ —
$x = \operatorname{tg}\alpha$; пара $(x; y)$ — $x = r\cos\alpha$, $y = r\sin\alpha$.
Трудно не сделать замену, а увидеть её; признаки — $\sqrt{1 - x^2}$,
$x^2 + y^2 = 1$, однородные выражения от $x$ и $y$.

- II.112: $\sqrt{1 - x^2} > a - x$ имеет решения. При $x = \cos\alpha$,
  $\alpha \in [0; \pi]$: $a < \sin\alpha + \cos\alpha$, наибольшее значение
  $\sqrt2$. Ответ: $a < \sqrt2$.
- II.113: $x(2x^2 - 1)\sqrt{1 - x^2} = a$ превращается в $\sin4\alpha = 4a$,
  $\alpha \in [0; \pi]$. Решения есть при $|a| \le \frac14$: четыре корня
  при $0 < |a| < \frac14$, пять при $a = 0$, два при $|a| = \frac14$
  (формула книги с четырьмя значениями $k$ даёт их с повторами).
- II.114: $x^2 + y^2 = 1$, $ax + by = 1$ — единственное решение:
  $\sin(\alpha + \varphi) = \frac1{\sqrt{a^2 + b^2}}$ имеет на периоде одно
  решение, только если правая часть равна $\pm1$. Ответ: $a^2 + b^2 = 1$ —
  прямая касается окружности.
- II.115: $3xy - 4x^2 < a(x^2 + y^2)$ имеет решения. Полярная замена даёт
  $a > \frac32\sin2\alpha - 2\cos2\alpha - 2$, наименьшее значение правой
  части $-\frac92$. Ответ: $a > -\frac92$.

### Б. Наибольшее и наименьшее значения

*Стр. 67–76, задачи II.126–II.136.*

**Изолировать параметр**: переписать условие как $a > f(x)$ или $a < f(x)$.
«При всех $x$» — $a$ больше наибольшего значения $f$; «есть решение» —
больше наименьшего (II.112, II.115, II.128).

- II.126: $(\operatorname{arctg}x)^2 + (\arccos y)^2 = \pi^2k$,
  $\operatorname{arctg}x + \arccos y = \frac\pi2$. Оценки областей значений:
  $0 \le \pi^2k < \frac{5\pi^2}4$, $k \in \{0; 1\}$; $k = 0$ не подходит.
  Ответ: $k = 1$, $x = \operatorname{tg}\frac{\pi(1 - \sqrt7)}4$,
  $y = \cos\frac{\pi(1 + \sqrt7)}4$.
- II.127: $\left|\left|\operatorname{tg}x - \frac12\right| - \frac12\right| \le a$
  при всех $x \in \left(-\frac\pi6; \frac\pi6\right)$, $a > 0$. Ответ:
  $a \ge \frac{\sqrt3}3$. Книга доказывает только достаточность; необходимость —
  точная верхняя грань $\frac{\sqrt3}3$ при $x \to -\frac\pi6$, она не
  достигается, поэтому граница входит в ответ.
- II.128: $-5 + 5a + \sin^2x + a(3 - \cos x)^3 > 0$ при всех $x$:
  $a > \frac{5 - \sin^2x}{(3 - \cos x)^3 + 5}$, и наибольшее значение $\frac5{13}$
  достигается при $\cos x = 1$ — там числитель наибольший, а знаменатель
  наименьший. Ответ: $a > \frac5{13}$. Близнец III.125, где вместо куба
  квадрат и пришлось разбирать трёхчлен.
- II.129: наибольшее $b$, при котором имеет решение неравенство, сводящееся к
  $\sqrt{b^5}(x - 4)^2 + \frac{\sqrt b}{(x - 4)^2} \le \frac23 b|\cos\pi x|$.
  Левая часть $\ge 2\sqrt{b^3}$ по неравенству о средних, правая $\le \frac23b$.
  Ответ: $b = \frac19$; равенство при $x = 1$ и $x = 7$.

**Вспомогательный угол**: $m\sin x + n\cos x = \sqrt{m^2 + n^2}\sin(x + \varphi)$.

- II.130: $(a^2 - 9)\cos x + 6a\sin x \le ab$ имеет решение при любом $a$.
  Наименьшее значение левой части $-(a^2 + 9)$, нужно $a^2 + ab + 9 \ge 0$
  при всех $a$. Ответ: $-6 \le b \le 6$. Ещё одна задача с кванторами:
  «при любом $a$ найдётся $x$».
- II.131: $|3\sin^2x + 2a\sin x\cos x + \cos^2x + a| \le 3$ при всех $x$.
  Выражение под модулем равно $\sqrt{a^2 + 1}\sin(2x - \varphi) + 2 + a$.
  Ловушка, о которой предупреждает книга: из-за модуля наибольшее значение
  может дать и $\sin = -1$; наибольшее значение модуля —
  $\sqrt{a^2 + 1} + |a + 2|$. Ответ: $-\frac{12}5 \le a \le 0$.
- II.132: $x^2 + 2px + 4p^2 - 5p + 3 \le 4\sin y - 3\cos y$, $0 \le y \le 2\pi$ —
  единственное решение. Левая часть не меньше $3p^2 - 5p + 3$, правая
  не больше 5, и максимум достигается в одной точке периода. Ответ:
  $p = -\frac13$ или $p = 2$.

**Метод оценки**: если $f(x) \le A \le g(x)$, то
$f(x) = g(x) \iff f(x) = A$ и $g(x) = A$.

- II.133: $(3a - 2)^2\log_3(-4x - 4x^2) = -(a + 1)^2\log_7(1 - 2x^2)$.
  На области определения левая часть $\le 0$, правая $\ge 0$. Ответ:
  при $a = -1$ $x = -\frac12$, при остальных $a$ решений нет.
- II.134: $\cos kx = 1 + 2\cos^2\left(\frac\pi4 + \frac x2\right)$:
  $\cos kx = 1$ и $x = \frac\pi2 + 2\pi m$. Ответ: при $k$, кратных 4,
  $x = \frac\pi2 + 2\pi m$; при остальных $k$ решений нет.
- II.135: $\log_2(3 - |\sin ax|) = \cos\left(\pi x - \frac\pi6\right)$,
  $2 < a < 5$, решение на $[2; 3]$: $x = \frac{13}6$. Ответ: $a = \frac{9\pi}{13}$
  или $a = \frac{15\pi}{13}$.
- II.136: $4\cos x\sin a + 2\sin x\cos a - 3\cos a = 2\sqrt7$ — оценка
  в два шага: вспомогательный угол по $a$ при фиксированном $x$, потом
  наибольшее значение по $x$: $\sqrt{28 - 12\left(\sin x + \frac12\right)^2} \le 2\sqrt7$.
  Ответ: при $a = \operatorname{arctg}\frac2{\sqrt3} + \frac\pi2 + 2\pi k$
  $x = -\frac\pi6 + 2\pi m$; при $a = -\operatorname{arctg}\frac2{\sqrt3} + \frac{3\pi}2 + 2\pi k$
  $x = -\frac{5\pi}6 + 2\pi m$; при остальных $a$ решений нет.

### В. Монотонность

*Стр. 78–83, задачи II.154–II.160.*

Используемые свойства: сумма возрастающих функций возрастает; произведение
неотрицательных возрастающих функций возрастает; монотонная функция
принимает каждое значение один раз, поэтому $f(u) = f(v) \iff u = v$,
а уравнение $f(x) = c$ имеет не больше одного корня.

**Приём 1: привести к $f(u) = f(v)$ и заменить на $u = v$.**

- II.154: $\sqrt{x + a} - \sqrt{y + b} = 1$, $\sqrt{y + a} - \sqrt{x + b} = 1$.
  Разность уравнений: $f(x) = f(y)$ для возрастающей
  $f(t) = \sqrt{t + a} + \sqrt{t + b}$, значит $x = y$. Ответ: при $a \ge b + 1$
  $x = y = \frac{(a - b - 1)^2}4 - b$, иначе решений нет.
- II.155 (книга дорешивает в §3): уравнение приводится к
  $f(x^2 - 2x + 3) = f(2|x - a| + 2)$ для функции $f(t) = 2^t\log_3t$,
  возрастающей на $[2; +\infty)$.
- II.156: при $0 < a < \frac14$ уравнение
  $x^2 + 2ax + \frac1{16} = -a + \sqrt{a^2 + x - \frac1{16}}$ после замены
  $t = \sqrt{\ldots}$ превращается в $f(x + a) = f(t)$ для $f(y) = y^2 + y$.
  Эта функция монотонна лишь на $\left[-\frac12; +\infty\right)$, и надо
  проверить, что оба аргумента там лежат. Ответ:
  $x = \frac14\left(2 - 4a \pm \sqrt{16a^2 - 16a + 3}\right)$.

**Приём 2: угадать корень уравнения $f(x) = c$ с монотонной $f$ —
он единственный.**

- II.157: $\sqrt[3]x + \sqrt{x - a} = \sqrt[3]a$. Ответ: $x = a$.
- II.158: $\sqrt{3x - 5} + \sqrt{3x + 11} = b$ — левая часть возрастает от 4.
  Ответ: при $b \ge 4$ один корень, при $b < 4$ корней нет.
- II.159: число решений первого уравнения не меньше числа решений второго.
  Первое монотонно — у него не больше одного корня; значит, у второго
  (квадратного) $D = 0$, $k = \pm\frac13$; при $k = -\frac13$ первое
  не определено. Ответ: $k = \frac13$.
- II.160: логарифмическое неравенство с единственным решением. Через
  возрастающую $f(t) = \log_3(\sqrt t + 1)\log_5(t + 1)$ с $f(4) = 1$
  сводится к квадратным неравенствам. Ответ: $a = 2$ — в книге он
  отдельной строкой не выписан.

### Г. Чётность, периодичность, обратимость

*Стр. 83–88, задачи II.172–II.180.*

- **Чётность сдвинутой функции**: $f(x + a)$ чётна $\iff$ $f(x + a) = f(-x + a)$
  при всех $x$ (при симметричной области определения). II.172:
  $f(x) = 5^x + \frac{25}{5^x}$, ответ $a = 1$.
- **Нечётность.** II.173: $3ax^3 - 2\sin\frac{8\pi a - x}5$ нечётна $\iff$
  $\sin\frac{8\pi a}5 = 0$; наименьшее положительное $a = \frac58$.
- **Вертикальная ось симметрии $x = b$** — это чётность $f(x + b)$:
  у многочлена $f(x + b)$ коэффициенты при нечётных степенях равны нулю.
  II.174: $x^4 + 2ax^3 - 2x^2 - 6ax$, ответ $a = -2$, $0$, $2$.
- **Период**: $f(x + T) = f(x)$ при всех допустимых $x$, и сама область
  определения переходит в себя при сдвиге. II.175: $\frac{\sin x}{a - \cos x}$
  имеет период $\pi$ $\iff a = 0$. II.176 — тонкое место: при $a = 2$
  дробное слагаемое обнуляется коэффициентом, но из области определения
  выпадают $x = \pm\sqrt3$, и функция непериодична. Ответ: при $a = -2$
  основной период $\frac{4\pi}3$; при $a = -1$ $f \equiv 0$ — периодическая
  без основного периода; при остальных $a$ непериодична.
- **Несоизмеримые периоды.** II.177: $2\cos ax - 3\operatorname{tg}^2x - 2 = 0$
  имеет единственное решение $\iff$ $a$ иррационально. Корень $x = 0$ есть
  всегда; оценка даёт $\cos ax = 1$, $\operatorname{tg}x = 0$, и второй корень
  появляется ровно при рациональном $a$. II.178: рациональные $a$, при которых
  у $\cos\frac{2x}{\sqrt5 + a^2}$ и $\operatorname{tg}\frac x{\sqrt{125} - 4a + 1}$
  есть общий период: в отношении периодов должна сократиться иррациональность.
  Ответ: $a = -1$ или $a = \frac15$. «Одинаковые периоды» книга понимает как
  «есть общий период»; если требовать равенства основных периодов, таких
  рациональных $a$ нет.
- **Обратимость**: для возрастающей $f$ уравнение $f(x) = f^{-1}(x)$
  равносильно $f(x) = x$. Возрастание обязательно: $y = -x^3$ и $y = -\sqrt[3]x$
  взаимно обратны, но пересекаются и вне прямой $y = x$. II.179:
  $\sqrt{a + \sqrt{a + \sin x}} = \sin x$; при $t = \sin x \in [0; 1]$ функции
  $t^2 - a$ и $\sqrt{t + a}$ взаимно обратны, и уравнение сводится
  к $t^2 - t = a$. Ответ: $-\frac14 \le a \le 0$ — та же задача, что II.90
  в II §1 Г, где она решена через квадратное уравнение относительно $a$.
  II.180 — та же II.156, решённая этим приёмом.

## Глава III. Квадратичная функция

Почти всё о трёхчлене задаёт «каркас»: знак $A$, знак $D$ и положение
вершины $x_0$. Отсюда устройство главы: сначала задачи на знаки $D$ и $A$,
потом на вершину, потом на корни — теорема Виета и расположение корней
относительно заданных точек.

### 1. Знаки дискриминанта и старшего коэффициента

*Стр. 152–161, задачи III.1–III.11.*

Таблица из шести картинок ($A > 0$ или $A < 0$; $D < 0$, $D = 0$, $D > 0$)
даёт всё нужное:

- $f(x) > 0$ при всех $x$ $\iff$ $A > 0$, $D < 0$; нестрогое $f(x) \ge 0$ —
  $A > 0$, $D \le 0$. Для «$< 0$» — $A < 0$.
- Неравенство $f(x) \le 0$ имеет ровно одно решение $\iff$ $A > 0$, $D = 0$.
- Если старший коэффициент зависит от параметра, сначала разбирается
  случай $A = 0$: там функция линейная, и таблица не работает.
- Многочлен степени не выше второй, обращающийся в ноль в трёх и более
  точках, — тождественный ноль: все коэффициенты равны нулю.

Приёмы по задачам главы:

**«При всех $x$» — через дискриминант.** III.1: множество значений
$8 \cdot 2^{\frac{x^2+ax-2}{x^2-x+1}} - 1$ лежит в $[0; 127]$ при всех $x$.
Двойное неравенство для показателя распадается на два квадратных неравенства
«при всех $x$» с положительными старшими коэффициентами — нужны $D_1 \le 0$
и $D_2 \le 0$. Ответ: $-1 \le a \le 6\sqrt2 - 4$.

**Ровно одно решение неравенства.** III.2: $mx^2 + (2 - m)x + 3 - 2m \le 0$.
При $m = 0$ решений — луч; при $m < 0$ — два луча; остаётся $m > 0$, $D = 0$.
Ответ: $m = \frac{8 \pm 2\sqrt7}{9}$.

**Вложение множеств — неравенство «при всех $x$».** III.3: все точки
с $y > 5(x - a)^2 - \sqrt{9 - a^2}$ лежат в области $y > x^2 - 3$. Модель:
$\{y > m\} \subset \{y > n\}$ $\iff$ $n \le m$. Значит,
$x^2 - 3 \le 5(x - a)^2 - \sqrt{9 - a^2}$ при всех $x$. Ответ: $a = 0$.

**Существование — два дискриминанта подряд.** III.4: наибольшее $a$, при котором
у $x^2 + 2y^2 + a^2 + xy - ax + ay = 3$ есть решение. Как квадратное по $x$:
нужно $D_x \ge 0$ — получается квадратное неравенство по $y$, у которого
тоже должно быть решение, то есть его дискриминант $\ge 0$. Ответ: $a = \sqrt7$.
III.5: единственная пара $(x; y)$ у
$ax^2 + (3a + 2)y^2 + 4axy - 2ax + (4 - 6a)y + 2 = 0$. После случая $a = 0$
дискриминант по $x$ равен $4a(a - 2)(y + 1)^2$; при $0 < a < 2$ он неположителен
и обращается в ноль только при $y = -1$, откуда единственная пара $(3; -1)$.
Ответ: $0 < a < 2$.

**«Следствие» и пустое множество.** III.6: когда $x^2 + b^2x - 8b = 0$ —
следствие $x^2 - ax + a = 0$. Если у второго уравнения корней нет, следствием
является любое уравнение. Если корни различны, оба должны быть корнями
первого — тогда у приведённых трёхчленов совпадают коэффициенты. Ответ:
$0 < a < 4$, $b$ любое; $a = 0$, $b = 0$; $a = 4$, $b = 2 \pm \sqrt2$;
$a = -64$, $b = 8$.

**Совокупность: корни не складываются механически.** III.7: четыре различных
корня у $\bigl(x^2 - (a + b)x + 1\bigr)\bigl(x^2 - (a - b)x + 1\bigr) = 0$.
Мало $D_1 > 0$ и $D_2 > 0$: корни разных скобок могут совпасть. Произведение
корней в обеих скобках равно 1, поэтому совпадение одного корня влечёт
совпадение второго, то есть $b = 0$. Ответ: $|a + b| > 2$, $|a - b| > 2$,
$b \ne 0$.

**Запрещённый корень.** III.8: единственное решение у системы, которая
сводится к $(1 - a)x^2 + x + 10 = 0$ при $x \ne -2$. Кроме $a = 1$ и $D = 0$
подходит и случай двух корней, один из которых равен запрещённому $-2$.
Ответ: $a = 1$, $a = \frac{39}{40}$, $a = 3$.

**«При любом $b$».** III.9: система $x^2 - 2x - y^2 = 0$, $y = ax - a + b$
разрешима при любом $b$. После подстановки $\frac D4 = b^2 - a^2 + 1$,
и это должно быть $\ge 0$ при всех $b$; случай $|a| = 1$ (уравнение
не квадратное) отпадает при $b = 0$. Ответ: $|a| < 1$.

**Тождество.** III.10: $a\cos\left(3x - \frac\pi2\right) + b\sin2\left(x + \frac{3\pi}2\right) + c\sin(x + \pi) = 0$
при всех $x \in \left[\frac18; \frac13\right]$ сводится к
$4a\cos^2x - 2b\cos x - a - c = 0$ на целом отрезке значений $\cos x$ —
бесконечно много нулей, значит, $a = b = c = 0$. III.11: система имеет
не меньше пяти решений, а распадается на две системы «прямая и кривая
второго порядка» — каждая даёт не больше двух, если не вырождается в тождество.
Ответ: $a = \pm1$, $b = -2$; или $b = 2$ при любом $a$.

### 2. Вершина параболы

*Стр. 162–168, задачи III.34–III.39.*

**Наибольшее и наименьшее на отрезке** зависят от того, где вершина:
левее отрезка, на нём (и к какому концу ближе) или правее. Знак
дискриминанта здесь не важен. III.34: $y = 2 - ax - 3x^2$ на $[-1; 1]$,
$x_0 = -\frac a6$. Ответ: при $a < -6$ $\max = -a - 1$, $\min = a - 1$;
при $-6 \le a < 0$ $\max = 2 + \frac{a^2}{12}$, $\min = a - 1$;
при $0 \le a < 6$ $\max = 2 + \frac{a^2}{12}$, $\min = -a - 1$;
при $a \ge 6$ $\max = a - 1$, $\min = -a - 1$.
В книге условие последнего случая напечатано как «$-\frac a6 \le 1$,
т. е. $a \ge -6$» — должно быть $-\frac a6 \le -1$, $a \ge 6$.

**После замены — отрезок новой переменной.** III.36: наименьшее значение
$4^x - 2^{3+x}a + 7a^2$ на $[-2; 0]$ отрицательно. Замена $t = 2^x \in \left[\frac14; 1\right]$,
$f(t) = t^2 - 8at + 7a^2$, вершина $t = 4a$ — три случая. Ответ:
$\frac1{28} < a < 1$. **В книге ответ неверный:**
$\frac1{28} < a \le \frac1{16}$ или $\frac14 \le a < 1$ — потерян средний
случай $\frac1{16} < a < \frac14$, где наименьшее значение $f(4a) = -9a^2 < 0$.

**Сначала — при каких $a$ задача вообще имеет смысл.** III.37: $x + y = 2a - 1$,
$x^2 + y^2 = a^2 + 2a - 3$, найти $a$ с наименьшим $xy$. Из системы
$xy = \frac32a^2 - 3a + 2$, и вершина $a = 1$ соблазняет, но при $a = 1$
система несовместна. Решения есть только при
$a \in \left[2 - \frac{\sqrt2}2; 2 + \frac{\sqrt2}2\right]$, вершина левее —
минимум на левом конце. Ответ: $a = 2 - \frac{\sqrt2}2$.

**Координаты вершины как функции параметра.** III.38: вершины
$4x^2 + 8ax - a$ и $4ax^2 - 8x + a - 2$ лежат по одну сторону от $y = -5$.
«По одну сторону» — произведение $(y_1 + 5)(y_2 + 5) > 0$, решать совокупность
двух систем не нужно. Ответ: $a < -4$ или $-\frac54 < a < 0$.
III.39: вершина параболы $y = -x^2 + 2ax - a^2 + a + 1$ — точка $(a; a + 1)$ —
бежит по прямой $y = x + 1$. Точка с наибольшей ординатой в области
$y \ge 2x$, $y \le -x^2 + 2ax - a^2 + a + 1$: при $a \le 1$ — $(a; a + 1)$;
при $1 < a \le 2$ — $\left(a - 1 + \sqrt{2 - a};\ 2(a - 1) + 2\sqrt{2 - a}\right)$;
при $a > 2$ область пуста. Последнего случая в ответе книги нет.

### 3. Теорема Виета

*Стр. 169–176, задачи III.51–III.59.*

**Сначала существование корней.** III.52: сумма квадратов корней
$4x^2 - 28x + a = 0$ равна $22{,}5$. По Виету $49 - \frac a2 = 22{,}5$, $a = 53$ —
но корни есть только при $a \le 49$. Ответ: таких $a$ нет. (В книге граница
напечатана как $a \le 38$.) III.53: в уравнении
$x^2 + x\sqrt{a^2 - 4a} - a - 2 = 0$ сам параметр допустим лишь при $a \le 0$
или $a \ge 4$; наименьшая сумма квадратов корней $a^2 - 2a + 4$ на этом
множестве — при $a = 0$.

**Длина корневого промежутка.** $|x_1 - x_2| = \frac{\sqrt D}{|A|}$. III.51:
решения $x^2 + ax - 1 < 0$ — интервал длины 5 при $a = \pm\sqrt{21}$.

**Знаки корней.** Корни разных знаков $\iff$ $\frac CA < 0$, и тогда $D > 0$
само собой. Существование корней видно и без дискриминанта: если
$A \cdot f(p) \le 0$ хоть в одной точке, корни есть. III.54:
$(a^2 - 2a + 2)x^2 + 2(a - 1)ax - 3a^2 = 0$ — старший коэффициент положителен,
$f(0) = -3a^2 \le 0$, корни есть всегда, при $a \ne 0$ — разных знаков.
Требование $x_1x_2 < |ax_1| - |ax_2|$ книга понимает как выполненное
при любой нумерации корней. Ответ: $-\frac12 < a < 0$ или $0 < a < \frac52$.

**Два положительных корня:** $D > 0$, $x_1 + x_2 > 0$, $x_1x_2 > 0$.
III.55: система $\log_2x + \log_2y = 6$, $y = 8 + k(x - 6)$ имеет два решения —
у $kx^2 - 2(3k - 4)x - 64 = 0$ два различных положительных корня. Ответ:
$k < -4$ или $-\frac49 < k < 0$. III.57: четыре решения у
$(x + a + 2)^2 + y^2 = 1$, $y^2 = 2ax$ — нужны два различных $x$ с $ax > 0$;
замена $t = ax$ сводит это к двум положительным корням. Ответ:
$-\frac13 < a < 0$.

**Замена $t = 3^x$: число решений — число положительных корней.**
III.58: $(p - 4)9^x + (p + 1)3^x + 2p - 1 = 0$ не имеет решений. После
случая $p = 4$ (корень $-\frac75$, решений нет) перебираются все способы
не иметь положительных корней: корней нет; оба отрицательны; оба нулевые;
один нулевой, другой отрицателен. Ответ: $p < \frac37$ или $p \ge 4$.

**Ровно один положительный корень** — три случая: корни разных знаков;
один корень ноль, другой положителен; кратный положительный корень.
III.59: $0{,}25^x - 2a \cdot 2^{-x} - 4b + 1 = 0$ имеет единственный корень.
Ответ — множество на плоскости $(a; b)$: $b > \frac14$ при любом $a$;
$b = \frac14$ при $a > 0$; кривая $b = \frac{1 - a^2}4$ при $a > 0$.

### 4. Расположение корней относительно заданных точек

*Стр. 176–192, задачи III.78–III.92.*

Типичные вопросы: корни (или ровно один корень) больше или меньше числа $p$;
корни между $p$ и $q$; корни вне промежутка.

**Удобный случай — дискриминант полный квадрат.** Корни находятся явно,
и задача сводится к сравнению двух выражений с числами.

- III.78: только один корень $x^2 - 2x(b + 1) + 6b - 3$ больше 2. Корни 3
  и $2b - 1$. Ответ: $b \le \frac32$ или $b = 2$ (кратный корень считается
  за один). В условии книги буква перепутана: спрашивают про $a$,
  а в трёхчлене $b$.
- III.79: один корень $x^2 - (2m + 1)x + m^2 + m - 2$ в $(0; 2)$, другой
  в $(3; 5)$. Корни $m - 1$, $m + 2$. Ответ: $1 < m < 3$.
- III.80: решение системы $x^2 - (3a - 2)x + 2a^2 - 4a < 0$, $x < 3$ —
  промежуток длины 5. Корни $2a$ и $a - 2$; разбираются случаи порядка
  корней и положения числа 3. Ответ: $a = -7$. **В книге ответ неверный:**
  $a = -7$, $0$, $3$. При $a = 0$ и $a = 3$ промежуток имеет длину 2:
  найденные значения не проверены на условия своих случаев — в первом
  случае книга такую проверку сделала и отбросила $a = -1$.
- III.81: $(x - a)(x - a - 2) > 0$ — следствие $x^2 - 4x + 3 < 0$. Интервал
  $(1; 3)$ должен лежать в объединении лучей. Ответ: $a \le -1$ или $a \ge 3$.
- III.82: ровно два $x$ у системы, где первое уравнение даёт множество
  $[-6; -1] \cup \{2; 3\}$, а второе — корни $a$ и $a + 4$. Ответ:
  $-6 \le a \le -5$, $a = -2$, $a = -1$.
- III.83: все решения $ax^2 + (1 - a^2)x - a > 0$ по модулю не больше 2.
  Неравенство $a(x - a)\left(x + \frac1a\right) > 0$; при $a \ge 0$ решения
  неограничены. Ответ: $-2 \le a \le -\frac12$.
- III.84: множество точек $(a; b)$, при которых решения одного квадратного
  неравенства содержатся в решениях другого. Корни «видны» по Виету:
  $-2a^2$, $a^2 + 3b^2$ и $-a^2 - 1$, $2b^2 + 16$. Ответ: полоса $|a| \le 1$
  внутри круга $a^2 + b^2 \le 16$.

**Общий случай — через значения в точках.** Когда корни явно не выписываются,
условие переводится на язык картинки, а картинка — в неравенства:

- **Утверждение 1.** Число $p$ лежит строго между корнями $\iff$
  $A \cdot f(p) < 0$. Требовать $D > 0$ не нужно: это неравенство уже
  гарантирует два корня.
- **Утверждение 2.** Оба корня меньше $p$ $\iff$ $D \ge 0$, $A \cdot f(p) > 0$,
  $x_0 < p$. Оба корня больше $p$ — то же с $x_0 > p$.

В книге формулировка утверждения 2 говорит «$p$ меньше корней», а система
под ней — для $p$ больше корней ($x_0 < p$, то есть $p > -\frac B{2A}$);
верный вариант для «меньше» дан замечанием ниже. Оба утверждения книга
не доказывает и отсылает к Г. В. Дорофееву, «Квадратный трёхчлен в задачах»
(Львов, 1991). Совет авторов — не заучивать, а понимать, как картинка
превращается в неравенства, и учиться на задачах: утверждения не покрывают
случаев, когда $p$ совпадает с корнем или точек две.

> III.85: число 2 между корнями $x^2 + (4a + 5)x + 3 - 2a = 0$: $f(2) = 17 + 6a < 0$.
> Ответ: $a < -\frac{17}6$. **В книге ответ с обратным знаком:** $a > -\frac{17}6$.

Типовые конфигурации, разобранные в книге:

- **Ровно один корень меньше $p$** (III.86, $x^2 + 2(a - 3)x + 9 - 2a = 0$, $p = 2$):
  $p$ между корнями, или $p$ совпадает с бо́льшим корнем, или $D = 0$
  с корнем меньше $p$. Ответ: $a < -\frac12$ или $a = 4$.
- **Оба корня в $(p; q)$** (III.87, $x^2 - ax + 2 = 0$ на $(1; 3)$):
  $D \ge 0$, $A f(p) > 0$, $A f(q) > 0$, $p < x_0 < q$. Без условия на вершину
  оба корня могли бы оказаться по одну сторону от отрезка. Ответ:
  $2\sqrt2 \le a < 3$.
- **Ровно один корень в $(p; q)$** (III.88, то же уравнение):
  $f(p) \cdot f(q) < 0$, и отдельно — $D = 0$ и корни на концах. Ответ:
  $3 \le a < \frac{11}3$ или $a = 2\sqrt2$.
- **Отрезок $[p; q]$ внутри корневого промежутка** (III.91,
  $(a - 2)x^2 - 2(a + 3)x + 4a = 0$, $x_1 < 2$, $x_2 > 3$):
  $A f(p) < 0$ и $A f(q) < 0$. Ответ: $2 < a < 5$.
- **Старший коэффициент с параметром** (III.92, все решения
  $(a - 1)x^2 - 2(a + 1)x + a - 3 = 0$ в $(-1; 5)$): сначала $a = 1$ (корень
  $-\frac12$ подходит), потом $D = 0$, потом обе системы для знака $A$
  сводятся к одной: $A f(-1) > 0$, $A f(5) > 0$, $D > 0$, $-1 < x_0 < 5$.
  Ответ книги: $a = 1$ или $a > \frac{19}8$.
- **Вложение множеств решений** (III.89, III.90). Книга сама формулирует
  правило: если у неравенства нет решений, следствием его является любое
  неравенство. III.90 ($ax^2 - x + 2 - a < 0$ влечёт $0 < x < 2$): ответ
  $\frac{2 - \sqrt3}2 \le a \le 2$. **В книге ответ неполный** —
  $\frac{2 - \sqrt3}2 \le a \le \frac{2 + \sqrt3}2$: в системе для $D > 0$
  напечатано $3a \le 0$ вместо $f(2) = 3a \ge 0$, и случай объявлен пустым.
  На деле при $\frac{2 + \sqrt3}2 < a \le 2$ подходит: например, при $a = 2$
  решения — $\left(0; \frac12\right)$.

**О пустом множестве решений книга непоследовательна.** В III.6 и III.90
«нет решений — условие выполнено». В III.89 («всякое решение $x^2 - x - 2 < 0$
больше любого решения $ax^2 - 4x - 1 \ge 0$») и III.92 («все решения уравнения
лежат в $(-1; 5)$») этот случай не учтён. Если учитывать его так же,
в III.89 вместо «таких $a$ нет» ответ $a < -4$, а в III.92 к ответу
добавляется $a < \frac13$. В подборку такие задачи стоит брать
с условием, где пустое множество решений оговорено явно, а ответ дан
к этому прочтению.

### 5. Задачи, сводящиеся к расположению корней

*Стр. 193–203, задачи III.121–III.128.*

Главный навык — заметить в задаче «скрытую» квадратичную функцию и
**после замены следить, какие значения может принимать новая переменная**:
$t = 2^x$ — положительные, $t = \cos x$ — отрезок $[-1; 1]$, $t = x^2$ —
неотрицательные, а условие на исходную переменную превращается в отрезок
для новой.

- III.121: система $(a - 1)y^2 - 2(3a + 1)y + 9a = 0$, $y = -\sqrt{x - 3} + 2$
  имеет решения $\iff$ у первого уравнения есть корень $y \le 2$.
  Ответ: $-\frac1{15} \le a \le 8$.
- III.122: $ax^4 - (a - 3)x^2 + 3a = 0$, один корень меньше $-2$, три
  остальных больше $-1$. При $t = x^2$: один корень больше 4, другой
  в $(0; 1)$. Ответ: $-\frac45 < a < 0$.
- III.123: множество решений системы содержит отрезок $[-2; -1]$ оси абсцисс.
  Для квадратного неравенства «$\le 0$ на отрезке» при ветвях вверх достаточно
  концов отрезка. Ответ: $-\frac72 \le a \le 1$.
- III.124: $a \cdot 4^x + (a + 2)2^x + 2 \le 0$ при всех $x \in [0; 1]$;
  $t = 2^x \in [1; 2]$, трёхчлен раскладывается: $(at + 2)(t + 1)$.
  Ответ: $a \le -2$.
- III.125: $-5 + 5a + \sin^2x + a(3 - \cos x)^2 > 0$ при всех $x$;
  $t = \cos x \in [-1; 1]$, разбор по знаку старшего коэффициента $a - 1$.
  Ответ: $a > \frac59$.
- III.126: неравенство с $\operatorname{tg}(\cos\sqrt{4\pi^2 - x^2})$ имеет
  конечное число решений $\iff$ корневой отрезок трёхчлена по
  $t \in [-\operatorname{tg}1; \operatorname{tg}1]$ задевает этот отрезок
  ровно в одной точке: касание ($D = 0$) или совпадение корня с концом.
- III.127 — **два параметра и кванторы:** найти $a$, при которых для всех
  $b > 0$ в интервале $0 < x < \frac12$ есть решение
  $\log_2(1 - x - x^2) = a\log_{1-x-x^2}2 + b$. Замена
  $t = \log_2(1 - x - x^2) \in (-2; 0)$ даёт $t^2 - bt - a = 0$ с корнем
  в $(-2; 0)$ при всех $b > 0$. Вершина правее нуля, значит, нужен меньший
  корень: $f(0) < 0$, $f(-2) > 0$, то есть $a > 0$ и $a < 4 + 2b$ при всех
  $b > 0$. Ответ: $0 < a \le 4$.
- III.128: система с $u = 2^{x+y}$, $v = 2^{2x-y}$ сводится к
  $v^2 - 2v - 2^a + 2 = 0$, но с ограничениями $u > 0$, $v > 0$, то есть
  $v > 2^a - 1$. Единственное решение — ровно один корень правее $2^a - 1$.
  Ответ: $a = 0$ или $\log_2\frac{5 - \sqrt5}2 \le a < \log_2\frac{5 + \sqrt5}2$.

## Глава IV, §2. Поиск необходимых условий

*Стр. 234–267, задачи IV.96–IV.154.*

Когда искать ответ напрямую трудно, сначала сужают круг «подозреваемых»:
выводят условие, которому ответ обязан удовлетворять, получают несколько
кандидатов и проверяют каждого. **Проверка обязательна:** необходимое условие
только отсекает лишнее, и в разобранных задачах она регулярно выбрасывает
кандидатов. Вводный пример книги: у неравенства область определения —
две точки $\{2; 3\}$, остаётся подставить обе.

### А. Симметрия

*Стр. 235–247, задачи IV.96–IV.104.*

Признаки задачи: выражение не меняется при какой-то замене — $x \to -x$,
$y \to -y$, $x \leftrightarrow y$, $(x; y) \to (-y; -x)$, — и требуется
единственность решения или заданное число решений.

Схема, сквозная для пункта:

1. Найти симметрию: вместе с решением $M$ решением будет и симметричная точка $M_1$.
2. Единственность требует $M = M_1$, то есть решение лежит на оси или
   плоскости симметрии: $x = 0$, $y = 0$, $x = y$. Это необходимое условие.
3. Подставить его — получить кандидатов для параметра.
4. Проверить каждого: на оси может оказаться несколько решений, а вне оси —
   пары симметричных решений.

Разобранные задачи:

- IV.96: $a(x^4 + 1) = y + 1 - |x|$, $x^2 + y^2 = 1$ — единственное решение.
  Симметрия $x \to -x$; при $x = 0$ кандидаты $a = 0$ и $a = 2$. При $a = 0$
  три решения $(1; 0)$, $(-1; 0)$, $(0; -1)$ — отпадает. При $a = 2$ первое
  уравнение даёт $y \ge 1$, второе $y \le 1$: решение $(0; 1)$ единственное.
  Ответ: $a = 2$.
- IV.97: $x^2 - 2c\sin(\cos x) + 2 = 0$ — единственное решение. Чётность,
  $x = 0$ даёт $c = \frac1{\sin1}$. Проверка оценкой: правая часть
  $\frac{2\sin(\cos x)}{\sin1} \le 2$, левая $x^2 + 2 \ge 2$, равенство только
  при $x = 0$. Ответ: $c = \frac1{\sin1}$.
- IV.98 — **симметрия спрятана.** Числа $3 - 2\sqrt2$ и $3 + 2\sqrt2$
  взаимно обратны, поэтому $(3 - 2\sqrt2)^y + (3 + 2\sqrt2)^y$ — чётная
  функция $y$. Система
  $(3 - 2\sqrt2)^y + (3 + 2\sqrt2)^y - 3a = x^2 + 6x + 5$,
  $y^2 - (a^2 - 5a + 6)x^2 = 0$, $-6 \le x \le 0$ симметрична по $y$; $y = 0$
  даёт кандидатов $-1$, $2$, $3$. При $a = -1$ левая часть не меньше 5, правая
  на $[-6; 0]$ не больше 5 — остаётся $(0; 0)$; при $a = 2$ решение $(-3; 0)$;
  при $a = 3$ решений нет. Ответ: $a = -1$ или $a = 2$.
- IV.99: $y \ge (x + y)^2 - x - 2y + a$, $x \ge (y - x)^2 - 3y + 2x + a$.
  Симметрия видна после раскрытия скобок: неравенства переходят друг в друга
  при $x \to -x$. При $x = 0$ — квадратное неравенство с единственным решением,
  $D = 0$, $a = \frac94$. Проверка сложением: $2x^2 + 2\left(y - \frac32\right)^2 \le 0$.
  Ответ: $a = \frac94$.
- IV.100: $4a^2x^4 + (2a - 8)x^2 + a + |a| = 0$ имеет ровно три корня
  на $(-1; 1]$. Корни идут парами $\pm x$, поэтому нечётное число даёт корень
  $x = 0$ — **или корень $x = 1$**, у которого пара $-1$ не попала
  в полуоткрытый промежуток. Для $t = x^2$: $t_1 = 0$ или $t_1 = 1$, и второй
  корень в $(0; 1)$. Ответ: $a < \frac{-1 - \sqrt{33}}4$ или $a = 1$.
- IV.101: при каких $a$ равносильны системы $x + 2y = 2 - a$, $-x + ay = a - 2a^2$
  и $x^2 - y^4 - 4x + 3 = 0$, $2x^2 + y^2 + (a^2 + 2a - 11)x + 12 - 6a = 0$.
  Первая при $a \ne -2$ имеет одно решение, при $a = -2$ — ни одного.
  При $a = -2$ вторая тоже пуста — равносильны. Иначе вторая должна иметь
  единственное решение, она симметрична по $y$, $y = 0$ даёт кандидатов
  $-1$, $1$, $3$; проверка оставляет $a = -1$. Ответ: $a = -2$ или $a = -1$.
- IV.102: $y \ge x^2 + 2a$, $x \ge y^2 + 2a$ — замена $x \leftrightarrow y$,
  $x = y$, $D = 0$, $a = \frac18$; проверка сложением. Ответ: $a = \frac18$.
- IV.103 — система трёх уравнений с тремя неизвестными; симметрия
  $x \leftrightarrow y$ становится видна, если второе уравнение переписать
  как $(x - 1)^2 + (y - 1)^2 + z^2 = a + 1$. Ответ: $a = 1$ (проверено вручную).
- IV.104 — **заданное число решений, а не единственность.**
  $(x - y)^2 = 6a - 14$, $x^2 + y^2 = 3(2 + a)$ — два решения. Здесь целая
  группа симметрий: вместе с $(x_0; y_0)$ решения $(y_0; x_0)$, $(-x_0; -y_0)$,
  $(-y_0; -x_0)$. Решений мало — значит, какие-то из них совпадают; перебор
  совпадений даёт $x = y$, откуда $a = \frac73$. Ответ: $a = \frac73$.
  Приём работает для любого «малого» числа решений: решения разбиваются на
  группы, и число меньше размера группы возможно только при совпадениях.

### Б. «Выгодная точка»

*Стр. 247–256, задачи IV.123–IV.130.*

Если требование должно выполняться **при всех** $x$ из множества $M$, оно
выполняется и в любой конкретной точке $M$. Подстановка удобной точки даёт
необходимое условие на параметр, потом — проверка. Рецепта выбора точки нет:
нужна такая, где выкладки простые и кандидатов мало. Вводный пример:
$a\sin^2x + a^2\cos^2x = 1$ при всех $x$. Точка $x = 0$ даёт $a = \pm1$ и
лишнюю проверку, точка $x = \frac\pi2$ — сразу $a = 1$.

**Равносильность.** Корень одного уравнения обязан быть корнем другого.

- IV.123: $4^{x+1} + 2^{x+4} = 2^{x+2} + 16$ и $|a - 9|\,3^{x-2} + a\,9^{x-1} = 1$.
  У первого единственный корень $x = 0$; подстановка во второе даёт $a \le 9$.
  Тогда второе — $(3^x - 1)(a\,3^x + 9) = 0$, и лишний корень $3^x = -\frac9a$
  мешает при $a < 0$, кроме $a = -9$. Ответ: $0 \le a \le 9$ или $a = -9$.
- IV.124: $\sin2x + a = \sin x + 2a\cos x$ и $2\cos2x + a^2 = 5a\cos x - 2$.
  Первое — $\left(\cos x - \frac12\right)(\sin x - a) = 0$; подстановка
  $x = \frac\pi3$ во второе даёт $a = 2$ или $a = \frac12$. Ответ: $a = 2$.
- IV.125: неравенство $\sqrt{x^2 + 4x + 3} \ge -1 - x$ (решения $x \ge -1$)
  и уравнение $|x - a| - |x + 1| = 2$. Точка $x = -1$ даёт $a = -3$ или $a = 1$.
  Ответ: $a = -3$. Без выгодной точки та же задача решена в II.64.

**«При всех $x$ на промежутке».**

- IV.126: $x + \sqrt{x^2 - 2ax} > 1$ при всех $x \in \left[\frac14; 1\right]$.
  Точка $x = 1$ даёт $a < \frac12$, точка $x = \frac14$ — уже $a < -1$.
  Подстановками конечный список не получить, поэтому достаточность доказывается
  отдельно: при $a < -1$ функция возрастает на отрезке. Ответ: $a < -1$.
  Прямое решение той же задачи — II.62.
- IV.127: $|2x^2 + ax + b| > 1$ не имеет решений на $[1; 3]$. Подстановка
  $x = 1$ и $x = 3$ в «$\le 1$», а $x = 2$ в «$\ge -1$» даёт три линейных
  неравенства, у которых одно решение. Ответ: $a = -8$, $b = 7$ — парабола
  $2(x - 2)^2 - 1$ касается краёв полосы в трёх точках.
- IV.128: $\cos nx \sin\frac{15x}{n^2}$ имеет период $5\pi$, $n$ — целое
  отрицательное. Точка $x = 0$: $\frac{75}{n^2}$ — целое. Ответ: $n = -1$, $n = -5$.

**«При любом значении другой буквы»** — это задачи с двумя параметрами
и кванторами: выгодная точка берётся для второго параметра.

- IV.129: найти $c$, при которых для любого $b$ система
  $(1 + 3x^2)^c + (b^2 - 4b + 5)^y = 2$, $x^2y^2 - (2 - b)xy + c^2 + 2c = 3$
  разрешима. Выгодное $b = 2$ (тогда $b^2 - 4b + 5 = 1$) даёт кандидатов
  $-3$, $0$, $1$; $c = 0$ отпадает при $b \ne 2$. Ответ: $c = 1$ или $c = -3$.
- IV.130: при каких $x$ для любого $y$ найдётся $z$ с
  $\sin(x + y + z) = \cos\left(2x + \frac\pi3\right)\left|y + \frac12\right| + \frac{\left|y - \frac32\right|}{2\cos x}$.
  Выгодное $y = -\frac12$ даёт $\cos x = \pm1$; $\cos x = 1$ отпадает при $y$
  вне $\left[-\frac12; \frac32\right]$. Ответ: $x = \pi + 2\pi k$
  (IV.129 и IV.130 проверены вручную).

### В. Разные приёмы

*Стр. 256–265, задачи IV.147–IV.154.*

Общая схема — «кольца» необходимых условий (рис. 104 книги): несколько
условий подряд, каждое сужает круг кандидатов, пока проверка не станет
короткой.

- IV.147: целое нечётное $n$ с $n^2 3^a - 3^a - 16n = 9 \cdot 3^{-a} - 3^{2-a}n^2$.
  После $t = 3^a$ — квадратное по $t$; сначала условие $D \ge 0$ как условие
  на $n$: $64n^2 \ge 9(n^2 - 1)^2$, откуда $n = \pm3$. Ответ: $a = 1$.
- IV.148: система $x - y \le 2$, $x + ay \ge 2$, $x - 2y \ge a$ имеет единственное
  решение $\Rightarrow$ три граничные прямые проходят через одну точку: $a = 2$
  или $a = -1$. При $a = -1$ две границы совпадают, решения — луч. Ответ: $a = 2$.
- IV.149: уравнение «корень плюс логарифм равно нулю» с целым решением.
  Корень $\ge 0$, значит, логарифм $\le 0$; это неравенство сворачивается
  в полный квадрат $\bigl(|x + \pi| - (q - \pi)\bigr)^2 \le 0$, дальше —
  целочисленность. Ответ: $q = 2\pi - 3$, $q = 2\pi - 2$, $q = 5$.
- IV.150: единственная целая пара с $12x^2 + 41xy + 35y^2 = 5$, $y + 1 < x$,
  $a^2x - 3ay < 6$. Разложение $(3x + 5y)(4x + 7y) = 5$ даёт четыре пары,
  условие $y + 1 < x$ оставляет $(30; -17)$ и $(18; -11)$; ровно одна должна
  удовлетворять последнему неравенству. Ответ:
  $-2 < a \le \frac{-17 - 3\sqrt{41}}{20}$ или $\frac{-17 + 3\sqrt{41}}{20} \le a < \frac16$.
- IV.151: каждое решение $\left(\frac{x + y}{x - y}\right)^2 = a$ удовлетворяет
  $\frac xy = b$. При $a = 1$ в решения входят пары $(x; 0)$ — отпадает;
  иначе квадратное по $\frac xy$ должно иметь один корень: $D = 16a = 0$.
  Ответ книги: $a = 0$, $b = -1$. Случай $a < 0$, когда у первого уравнения
  нет решений, книга не рассматривает — та же непоследовательность,
  что в III.89 и III.92.
- IV.152: натуральные $x, y, u, v$ с $(x + y)(x + y + 20) = (140 - \alpha)(\alpha - 80)$,
  $\alpha(8u^2 + 2v^2 - \alpha) = (4u^2 - v^2)^2$. Первое: $80 < \alpha < 140$;
  второе как квадратное по $\alpha$: $\alpha = (2u \pm v)^2$ — полный квадрат.
  Кандидаты $81$, $100$, $121$. Ответ: $\alpha = 100$.
- IV.153: минимум $f(x)$ не меньше 1 и достигается при $x = 1$. Сначала
  $f'(1) = 0$, потом знак производной слева от 1 — остаётся $p = 2$, затем
  условие на $m$: $|\operatorname{ctg}2\pi m|(1 + m)(1 - 2m) \ge 0$. Ответ:
  $p = 2$ и $m \in (-1; \frac12)$, $m \ne -\frac12$, $m \ne 0$; или
  $m = \frac14 + \frac n2$, $n \in \mathbb Z$. **Ответ книги неполный**, см.
  таблицу ошибок.
- IV.154: $|x - c| + |x - d| = A$ имеет единственное решение $\iff$ $c = d$
  и $A = 0$: при $c \ne d$ минимум левой части достигается на целом отрезке.
  В книге условие и решение расходятся в знаке, см. таблицу ошибок.
