# Банки задач

Задачи и учебники по темам — олимпиады, вступительные, задачники и конспекты
учебников. Сайт собирается из личного хранилища скриптом выкладки и руками
не правится: страница `index.html` с `assets/bank.js` только показывает
`data/banki.json` и файлы из `data/uchebniki/` — конспекты и задачи книг.

Главная — раздел на тему со строками вкладок. Вкладки темы:

- «Задачи» — олимпиадные задачи, с фильтром по источнику и по меткам;
- «Метки» — реестр меток: все метки по типам, у каждой число задач и сколько
  раз она решающая; строка ведёт в «Задачи» с фильтром по ней;
- «Другие источники» — вступительные и сборники, без меток;
- «Учебники» — конспекты; у книги, задачи которой есть в банке, рядом
  с конспектом вкладка «Задачи», файл с ними грузится только тогда.

Карточка задачи в покое — одно условие; нажатие раскрывает код, источник,
ответ, пару, решение и справку. Метки в справке — кнопки: нажатие добавляет
метку в фильтр. Меток в фильтре может быть несколько, видны задачи со всеми;
режим «решающая» ищет метки только как решающий шаг.

Адрес помнит выбор: `#parametr` — задачи темы, `#parametr/ommo` — один
источник, `#parametr/Техника:Виет` — фильтр по метке (меток через `/` может
быть несколько, `/решающая` — режим), `#parametr/ФТ-2026-в1-7` — задача
раскрыта, страница у неё, `#parametr/metki` — реестр меток,
`#parametr/drugie` — другие источники, `#parametr/uchebniki` — учебники,
`#parametr/uchebniki/<конспект>` — конспект,
`#parametr/uchebniki/<конспект>/zadachi` — задачи книги. Голый код задачи
сам находит свою вкладку.
