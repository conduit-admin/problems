# Банки задач

Задачи одной темы из многих источников — олимпиады, вступительные, задачники, —
каждая с источником и ответом. Сайт собирается из личного хранилища скриптом
выкладки и руками не правится: страница `index.html` с `assets/bank.js` только
показывает `data/banki.json`.

Карточка задачи в покое — одно условие; нажатие раскрывает код, источник,
ответ, пару, решение и справку.

Адрес помнит выбор: `#parametr` — банк, `#parametr/ommo` — один источник,
`#parametr/ФТ-2026-в1-7` — задача раскрыта, страница у неё. Ссылка на задачу —
её код в раскрытой карточке.
