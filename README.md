# Банки задач

Задачи и учебники по темам — олимпиады, вступительные, задачники и конспекты
учебников. Сайт собирается из личного хранилища скриптом выкладки и руками
не правится: страница `index.html` с `assets/bank.js` только показывает
`data/banki.json` и конспекты из `data/uchebniki/`.

Главная — раздел на тему со строками «Задачи» и «Учебники». Карточка задачи
в покое — одно условие; нажатие раскрывает код, источник, ответ, пару,
решение и справку. Конспект открывается своей страницей.

Адрес помнит выбор: `#parametr` — задачи темы, `#parametr/ommo` — один
источник, `#parametr/ФТ-2026-в1-7` — задача раскрыта, страница у неё,
`#parametr/uchebniki` — учебники, `#parametr/uchebniki/<конспект>` — конспект.
