# Банки задач

Задачи одной темы из многих источников — олимпиады, вступительные, задачники, —
каждая с источником и ответом. Сайт собирается из личного хранилища скриптом
выкладки и руками не правится: страница `index.html` с `assets/bank.js` только
показывает `data/banki.json`.

Адрес помнит выбор: `#parametr` — банк, `#parametr/ommo` — банк, один источник.
